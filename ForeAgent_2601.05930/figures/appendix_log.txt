# Overview
## Description
This dataset focuses on predicting subjective qualities of question-answer (QA) pairs. Unlike objective questions with clear answers, these QA pairs come from diverse sources and involve human judgment about subjective aspects such as clarity, relevance, and quality.

The dataset was collected by Google Research's CrowdSource team to advance NLP models' ability to understand and evaluate subjective, human-like content. Each QA pair was rated by multiple human annotators with minimal instructions, encouraging natural and intuitive assessments. The goal is to train models that can predict these subjective ratings from textual features of questions and answers.

The dataset covers questions and answers from approximately 70 websites, representing a wide variety of topics and linguistic styles. It provides a benchmark for evaluating how well machine learning models can approximate human perception in Q&A quality assessment.

## Evaluation
Submissions are evaluated using the **mean column-wise Spearman's rank correlation coefficient** between predicted and actual scores. Each target column corresponds to one subjective label, and the final score is the average Spearman correlation across all labels.

Predictions must be in the range `[0, 1]` and follow this format:

```

qa_id,question_asker_intent_understanding,...,answer_well_written
6,0.0,...,0.5
8,0.5,...,0.1
18,1.0,...,0.0

```

## Dataset Description
The dataset contains question-answer pairs primarily from StackExchange. Each row represents one question and one corresponding answer, along with metadata and 30 target labels.

- **Question features:** `question_title`, `question_body`
- **Answer features:** `answer`
- **Targets:** 30 continuous labels (01), representing subjective attributes (e.g., clarity, usefulness, relevance)

Questions may appear multiple times with different answers in the training set. Test data contains unique questions.

This is not a binary classification task; targets represent averaged human ratings. Models must therefore produce continuous predictions within the same range.

### Files
- **train.csv**  Training data with 30 labeled target columns  
- **test.csv**  Test data (predict 30 targets for each row)

## Implications for Model Design

### 1. Multi-target structure and shared representations

**Observation:** Targets are highly correlated, especially within families (instructional types, quality metrics); question-group means explain most variance.

**Model implications:**

- **Shared representations across targets** can be highly efficient:
  - A common text embedding that feeds multiple task-specific heads can exploit cross-target redundancy.
  - However, too much sharing can cause **negative transfer** for targets with opposing correlations (e.g., fact-seeking vs opinion-seeking).
- High inter-target correlation means that a model could implicitly infer some labels from others; evaluation of truly independent predictive capability should avoid reusing predicted labels as inputs.
- Because question-level features explain most variance, representations that heavily encode **question semantics** will dominate; answer-specific nuances may be under-modeled unless explicitly emphasized (e.g., by joint QA encoding).

**Evaluation impact:**

- Validation metrics may look artificially strong if the model is mostly modeling **shared latent factors** (e.g., "instructionalness", "overall quality") rather than target-specific detail.

### 2. Handling discretized, skewed labels

**Observation:** Many targets are quasi-ordinal with few discrete levels, and some are extremely imbalanced (rare 1's or rare non-zero values).

**Model implications:**

- Models trained with standard regression loss may:
  - Over-smooth predictions into the middle of the [0,1] range, which is **suboptimal for step-like labels**.
  - Underfit rare categories (e.g., spelling-type, "not really a question") due to lack of positive examples.

  - With discretized labels, **calibration at step boundaries** (0.33, 0.66, 1.0, etc.) is crucial. Models with smooth output distributions might achieve good MSE but misorder examples across these thresholds.

**Evaluation impact:**

- Continuous error metrics will not fully capture **ordinal misclassification costs**; evaluation should inspect confusion around threshold boundaries and performance on rare positive labels.
- Comparing per-target score distributions of predictions vs ground truth can reveal **mode collapse** (e.g., model never predicting extreme values).


### 3. Representation of question and answer text

class QADataset(Dataset):
    def __init__(self, df, text_columns, target_columns, embedder, is_test=False):
        self.df = df
        self.text_columns = text_columns
        self.target_columns = target_columns
        self.embedder = embedder
        self.is_test = is_test

        self.embeddings = {}

class CrossAttentionModel(nn.Module):
    def __init__(self, embed_dim, num_heads, output_size):
        super(CrossAttentionModel, self).__init__()
        self.embed_dim = embed_dim
        self.num_heads = num_heads

        # Question and answer encoders
        self.question_proj = nn.Linear(embed_dim, embed_dim)
        self.answer_proj = nn.Linear(embed_dim, embed_dim)

        # Cross-attention layers
        self.cross_attention = MultiheadAttention(
            embed_dim, num_heads, batch_first=True
        )

        # Main network
        self.fc1 = nn.Linear(embed_dim * 3, 1024)
        self.bn1 = nn.BatchNorm1d(1024)
        self.drop1 = nn.Dropout(0.3)

        self.fc2 = nn.Linear(1024, 512)
        self.bn2 = nn.BatchNorm1d(512)
        self.drop2 = nn.Dropout(0.3)

        self.fc3 = nn.Linear(512, 256)
        self.bn3 = nn.BatchNorm1d(256)
        self.drop3 = nn.Dropout(0.3)

        self.output = nn.Linear(256, output_size)

    def forward(self, question_title, question_body, answer):
        # Combine question parts
        question = (question_title + question_body) / 2

        # Project to same dimension
        question_proj = self.question_proj(question.unsqueeze(1))
        answer_proj = self.answer_proj(answer.unsqueeze(1))

        # Cross attention
        attn_output, _ = self.cross_attention(
            query=question_proj, key=answer_proj, value=answer_proj
        )
        attn_output = attn_output.squeeze(1)

        # Combine features
        combined = torch.cat([question, answer, attn_output], dim=1)

        # Main network
        x = torch.relu(self.bn1(self.fc1(combined)))
        x = self.drop1(x)

        x = torch.relu(self.bn2(self.fc2(x)))
        x = self.drop2(x)

        x = torch.relu(self.bn3(self.fc3(x)))
        x = self.drop3(x)

        x = torch.sigmoid(self.output(x))
        return x


def spearman_correlation(y_true, y_pred):
    corr = np.zeros(y_true.shape[1])
    for i in range(y_true.shape[1]):

    return np.mean(corr)

from sklearn.decomposition import TruncatedSVD
from sklearn.model_selection import KFold
from sklearn.multioutput import MultiOutputRegressor
from scipy.stats import spearmanr
import lightgbm as lgb


def mean_spearmanr(y_true, y_pred):
    scores = []
    for i in range(y_true.shape[1]):
        score, _ = spearmanr(y_true[:, i], y_pred[:, i])
        if np.isnan(score):
            score = 0
        scores.append(score)
    return np.mean(scores)


# Read data
train_df = pd.read_csv("./input/train.csv")
test_df = pd.read_csv("./input/test.csv")
sample_submission = pd.read_csv("./input/sample_submission.csv")

# Get target columns (excluding qa_id)
target_cols = [col for col in sample_submission.columns if col != "qa_id"]

# Combine text features for train and test datasets
for df in [train_df, test_df]:
    df["text"] = (
        df["question_title"].fillna("")
        + " "
        + df["question_body"].fillna("")
        + " "
        + df["answer"].fillna("")
    )

# Initialize TF-IDF vectorizer with ngram_range (1,2)
tfidf = TfidfVectorizer(max_features=10000, stop_words="english", ngram_range=(1, 2))
X_train_tfidf = tfidf.fit_transform(train_df["text"])
X_test_tfidf = tfidf.transform(test_df["text"])

# Generate second feature set using TruncatedSVD reduction to 300 components
n_components = 300
svd = TruncatedSVD(n_components=n_components, random_state=42)
X_train_svd = svd.fit_transform(X_train_tfidf)
X_test_svd = svd.transform(X_test_tfidf)

# Targets
y = train_df[target_cols].values

# LightGBM parameters
lgb_params = {
    "n_estimators": 500,
    "learning_rate": 0.05,
    "objective": "regression",
    "random_state": 42,
    "n_jobs": 5,
    "device":"gpu",
}

# Setup 5-fold CV and ensemble weight tuning
kf = KFold(n_splits=5, shuffle=True, random_state=42)
fold_spearman = []
optimal_alphas = []
fold_idx = 1
alpha_candidates = np.linspace(
    0, 1, 11
)  # Candidate weights from 0 to 1 in steps of 0.1

for train_index, valid_index in kf.split(X_train_tfidf):
    # Split features and targets
    X_tr_tfidf, X_val_tfidf = X_train_tfidf[train_index], X_train_tfidf[valid_index]
    X_tr_svd, X_val_svd = X_train_svd[train_index], X_train_svd[valid_index]
    y_tr, y_val = y[train_index], y[valid_index]

    # Train models on respective features
    # GPU-ized by LLM
    model_tfidf = MultiOutputRegressor(lgb.LGBMRegressor(**lgb_params))
    model_tfidf.fit(X_tr_tfidf, y_tr)
    y_pred_tfidf = model_tfidf.predict(X_val_tfidf)

    # GPU-ized by LLM
    model_svd = MultiOutputRegressor(lgb.LGBMRegressor(**lgb_params))
    model_svd.fit(X_tr_svd, y_tr)
    y_pred_svd = model_svd.predict(X_val_svd)

    # Grid search for best ensemble weight on validation set
    best_score = -np.inf
    best_alpha = None
    for alpha in alpha_candidates:
        y_pred_ensemble = alpha * y_pred_tfidf + (1 - alpha) * y_pred_svd
        score = mean_spearmanr(y_val, y_pred_ensemble)
        if score > best_score:
            best_score = score
            best_alpha = alpha

    optimal_alphas.append(best_alpha)
    fold_spearman.append(best_score)
    print(f"Fold {fold_idx} best alpha: {best_alpha:.2f}, Spearman: {best_score:.4f}")
    fold_idx += 1

cv_mean_spearman = np.mean(fold_spearman)
final_alpha = np.mean(optimal_alphas)
print(f"\nMean Spearman Correlation from 5-fold CV: {cv_mean_spearman:.4f}")

final_model_tfidf = MultiOutputRegressor(lgb.LGBMRegressor(**lgb_params))
final_model_tfidf.fit(X_train_tfidf, y)
# GPU-ized by LLM
final_model_svd = MultiOutputRegressor(lgb.LGBMRegressor(**lgb_params))
final_model_svd.fit(X_train_svd, y)

# Predict on test data for both models, ensemble using optimal weight
test_pred_tfidf = final_model_tfidf.predict(X_test_tfidf)
test_pred_svd = final_model_svd.predict(X_test_svd)
test_preds = final_alpha * test_pred_tfidf + (1 - final_alpha) * test_pred_svd
test_preds = np.clip(test_preds, 0, 1)

submission_df.insert(0, "qa_id", test_df["qa_id"])
